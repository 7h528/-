# 校园活动聚合站

一个简洁的校园活动信息聚合网页，帮助学生快速发现和筛选校园内的各类活动。

## 项目结构

```
├── index.html   # 页面结构
├── style.css    # 基础样式
├── script.js    # 交互逻辑与数据
└── README.md    # 项目说明
```

## 功能说明

- **分类筛选**：按学术、体育、文艺、社团、志愿、就业六大类别筛选活动
- **状态筛选**：按"即将开始"或"已过期"筛选活动
- **倒计时显示**：实时显示距离活动开始的时间，过期活动自动置灰
- **活动发布**：通过表单发布新活动，数据保存在 localStorage 中
- **本地持久化**：使用 localStorage 保存活动数据，刷新页面不丢失

## 数据说明

项目内置 26 条模拟活动数据，覆盖六大分类。首次加载时自动写入 localStorage，后续以 localStorage 中的数据为准。

## 信息风险处理

- 活动数据存储在浏览器本地（localStorage），不涉及后端数据库
- 清除浏览器数据后活动将恢复为默认数据
- 不同浏览器/设备间数据不共享
